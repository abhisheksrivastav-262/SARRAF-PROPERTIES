## Media source mapping

- Bundled originals in `src/assets` remain untouched and are selectable in CMS page editors.
- The Media Library has an explicit import action that copies a bundled image to the private `site-media` bucket with a deterministic path. It refuses duplicate metadata and rolls back the uploaded object if metadata creation fails.
- Existing Supabase `media_assets` are listed by page and section in their editors and the library; uploaded CMS videos and images use the existing bucket and configured MIME/size limits.
- Draft objects remain private. Published page/object access continues to be enforced by the existing RLS policies.
- No existing asset reference or production database row was rewritten while creating this inventory.
